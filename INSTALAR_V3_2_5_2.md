# Instalacion V3.2.5.2

1. Confirma que V3.2.5.1 ya este instalada y tenga skills asociadas a uno o mas cursos.
2. Copia el contenido de este parche sobre `C:\xampp\htdocs\DEVIOZ-VIDEOS`, respetando las carpetas.
3. No reemplaces ni borres `uploads`.
4. Esta version **NO requiere importar SQL**.
5. En el navegador usa `Ctrl + F5`.
6. Entra con un usuario que tenga una capacitacion asociada a un curso con skills.
7. Abre `Aprendizaje -> Mis skills` y revisa el perfil tecnologico.
8. Revisa tambien `Mi progreso`, donde aparece un resumen de competencias.

No hagas commit hasta terminar las pruebas funcionales.
