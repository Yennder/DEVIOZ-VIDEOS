# TechFlix V3.2.3 - Sistema de notificaciones

Este avance agrega un centro de notificaciones reutilizable para Learning Lab y la interacción entre usuarios.

## Incluido

- Campana de notificaciones en la barra superior con contador de pendientes.
- Panel desplegable con las notificaciones más recientes.
- Página `Mis notificaciones` con historial, marcar como leída, marcar todas y eliminar.
- Notificación al asignar una capacitación nueva.
- Aviso cuando cambia la fecha límite de una capacitación asignada.
- Recordatorio cuando faltan 3 días o menos para el vencimiento.
- Notificación cuando todas las lecciones están completas y la evaluación queda disponible.
- Notificación al aprobar y completar una capacitación.
- Notificación cuando se agotan los intentos de una evaluación.
- Notificación cuando se obtiene un logro.
- Notificación cuando otro usuario responde un comentario.
- Protección contra notificaciones duplicadas mediante una clave única por evento.
- El sistema funciona con modo claro y oscuro y se adapta a pantallas pequeñas.

## No incluido todavía

- Certificados: corresponde a V3.2.4.
- Skills y reportes de competencias: corresponde a V3.2.5.
- Notificaciones por correo o push del navegador: no forman parte de esta primera versión.
