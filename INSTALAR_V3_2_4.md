# Instalar V3.2.4

1. Copia los archivos del parche sobre tu proyecto actual.
2. No reemplaces `uploads`.
3. En phpMyAdmin selecciona `devioz_videos`.
4. Importa solamente `database/migracion_v3_2_4_certificados.sql`.
5. Haz `Ctrl + F5`.
6. Prueba primero con un usuario que ya tenga una capacitación completada.
