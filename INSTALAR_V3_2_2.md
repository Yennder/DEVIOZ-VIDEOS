# Instalar V3.2.2

1. Confirma que V3.2.1 ya funciona y esta guardada en Git.
2. Copia los archivos del parche sobre tu carpeta `DEVIOZ-VIDEOS`, respetando las rutas.
3. No importes SQL: esta version no cambia la estructura de la base de datos.
4. No reemplaces ni borres `uploads`.
5. En el navegador usa `Ctrl + F5`.
6. Realiza las pruebas indicadas en el chat.
7. Cuando todo funcione, registra el avance en Git:

```bash
git status
git add .
git commit -m "feat: agrega retroalimentacion final de evaluaciones"
git push
```
